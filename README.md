# VCSNet

Repository for **Overcoming Phenotypic Ambiguity in Tree Detection: A Vegetation-Contrast and Scale-Aware Counting Network for Complex Urban–Rural Scenes**.

VCSNet is an RGB-based network for tree counting and localization in complex urban and rural scenes. It combines vegetation-contrast evidence and semantically conditioned modulation (VCSM), count-aware auxiliary training (CAAT), and multi-branch residual enhancement (MBRE).

## Release status

**Code, pretrained weights, and sample data will be uploaded after the implementation and release files have been reviewed.** They are not yet included in this repository.

## Planned contents

- Model implementation and training, inference, validation, and test scripts.
- A validation-selected pretrained model checkpoint.
- A small curated subset of training and validation images with point annotations.
- Installation and usage instructions.

Large files will be provided through GitHub Releases. Git LFS will not be required.

## Data availability

The full Julu dataset is subject to confidentiality restrictions and will not be publicly released. A limited sample subset is planned for release. Requests for additional data may be directed to the authors, subject to applicable permissions and confidentiality restrictions.
